
# Contributing Guidelines

### Google Learn with Communities — Community Challenge 2026

Thank you for your interest in contributing to this project! We appreciate every suggestion, improvement and contribution that helps make this community leaderboard better.

Before making any changes, please take a moment to read the guidelines below.

---

## 📌 1. Raise an Issue First

Before making any changes to the project:

- Create a GitHub Issue explaining what you want to change or improve.
- Clearly describe the problem or proposed feature.
- Wait for discussion and approval before starting development.
- Do not make commits or submit pull requests for unapproved changes.

**Please discuss your idea first. Avoid unnecessary or duplicate contributions.**

## 💬 2. Discussion & Approval

- Wait for the project maintainer's response.
- Be open to feedback and suggestions.
- Make sure the proposed changes align with the project's goals.
- Start working only after receiving approval.

For further discussion or clarification, you can contact the project maintainer directly.

## 🛠️ 3. Making Contributions

Once your issue has been approved:

1. Fork the repository.
2. Create a separate branch for your contribution.
3. Make the approved changes.
4. Keep your code clean, readable and organised.
5. Test your changes before submitting them.
6. Commit your work with a meaningful commit message.
7. Open a Pull Request referencing the approved issue.

## 🎨 4. Code & Design Guidelines

Please follow these basic guidelines:

- Maintain the existing project structure.
- Follow the existing coding and naming conventions.
- Keep the interface responsive across desktop and mobile devices.
- Maintain the existing Google-inspired colour system.
- Avoid unnecessary dependencies.
- Do not introduce unrelated changes.
- Keep the user interface clean, accessible and consistent.

## 🚫 5. Things to Avoid

- Do not commit directly to the main branch.
- Do not start unapproved features or modifications.
- Do not submit unrelated changes.
- Do not upload personal information, access codes or sensitive participant data.
- Do not overwrite existing functionality without discussion.
- Do not submit duplicate issues or pull requests.

## 🤝 6. Need Help?

If you have questions, ideas or need clarification before contributing, feel free to contact the project maintainer directly.

We are happy to discuss suggestions, improvements and potential contributions.

Please remember that communication comes first.

## ⭐ 7. A Final Note

This project is built for the community, and every meaningful contribution matters.

Let's work together to make the Google Learn with Communities leaderboard better, more useful and more engaging for everyone.

**Discuss first. Get approval. Then contribute.**

Thank you for being part of the community! 🚀
